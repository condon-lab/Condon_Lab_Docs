### Publication 
Congrats! You've reached a huge milestone in your academic career of getting your first publication or another one under your belt. Make sure to add to your CV, the group Zotero, post on LinkedIn, and write a summary snippet to post it on the group website, straight off the press. 

Make sure to fork your GitHub into the Condon-Lab organization. 

* Update the citation in your Readme file to include the publication citation with the associated DOI link. 
* Name the forked repository as `[Name]_[publication year]_[brief repo name]` 
    - Example: `Spinti_2023_RiverFramgmentation` 
* Add description "Repository supporting [citation]"
    - Example: Repository supporting “De la Fuente LA, MR Ehasnai, HJ Gupta, LE Condon (2024). Toward interpretable LSTM-based modeling of hydrological systems. Hydrology and Earth Sciences, Vol 28 Issue 4, 945–971." https://hess.copernicus.org/articles/28/945/2024/
